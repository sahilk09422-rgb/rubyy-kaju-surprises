RUBYY + KAJU SURPRISE WEBSITE

HOW TO OPEN:
1. Keep index.html and rubyy-photo.jpeg in the same folder.
2. Double-click index.html to open the website in Chrome.
3. To publish it online, upload BOTH files (index.html and rubyy-photo.jpeg) to the root of a public GitHub repository and enable GitHub Pages.

IMPORTANT:
- Do not rename the photo unless you also update its name in index.html.
- Test the page on your phone after publishing.
